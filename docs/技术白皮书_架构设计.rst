系统架构概述
============

Omni Deck 采用多层异构混合架构设计，将本地游戏引擎、Web 端渲染层与后台微服务深度融合：

* **游戏大厅**：融合 RPG Maker, Flash, Wasm, Wine 独立进程；
* **媒体阅读中枢**：支持漫画 (CBZ)、小说 (TXT) 与技术文档 (Markdown, RST)；
* **局域网与网络共享**：基于底层物理 Socket 的 IP 判定与毫秒级权限闸门控制。

内存级 RST 渲染引擎
===================

对于 reStructuredText 格式的技术文档，Omni Deck 采用了创新的 **RAM LRU In-Memory Cache** 架构：

1. 当客户端请求 ``.rst`` 文件时，服务端实时校验文件 ``mtime``；
2. 命中内存缓存时直接以 **0 毫秒** 延迟吐出 HTML；
3. 磁盘上 **0 临时文件产生**，极大保护 Steam Deck 固态硬盘寿命与整洁度。
